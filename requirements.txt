# 원격주행 적응형 카메라 뷰 선택 시스템 — 의존성
# CLAUDE.md B.1 기준. 최초 설치 후 `pip freeze`로 버전을 고정하여 재커밋한다.
#
# 설치:
#   python3 -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#
# ⚠️ 1) numpy는 2.x를 쓰면 안 된다.
#    nuscenes-devkit 1.2.0이 `numpy<2.0.0`을 고정한다. 다른 프로젝트와 공용 venv를
#    쓰면 numpy가 강제 다운그레이드되므로, 이 프로젝트는 반드시 전용 venv를 쓴다.
#
# ⚠️ 2) torch/torchvision은 GPU에 맞는 휠이 필요하다.
#    RTX 5060 Ti(Blackwell, sm_120)에서는 PyPI 기본 인덱스의 휠(cu130 동봉)로 동작한다.
#      python3 -m venv .venv && source .venv/bin/activate
#      pip install "numpy<2" torch torchvision
#    (검증 2026-09: RTX 5060 Ti + 드라이버 610.88 → torch 2.14.0+cu130, CUDA=True)
#    옛 RTX 4070 머신에서는 cu124 인덱스가 필요했다 — 머신이 바뀌면 재확인할 것.
#    정확한 버전 고정은 requirements-lock.txt 참조.
