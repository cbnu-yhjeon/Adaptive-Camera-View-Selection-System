# 원격주행 적응형 카메라 뷰 선택 시스템 — 의존성
# CLAUDE.md B.1 기준. 최초 설치 후 `pip freeze`로 버전을 고정하여 재커밋한다.
#
# 설치:
#   python3 -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#
# ⚠️ torch/torchvision은 시스템 CUDA 드라이버에 맞는 휠을 받아야 한다.
#    기본 `pip install torch`는 최신(cu130) 휠을 받는데, 이 환경의 드라이버는
#    CUDA 12.6이라 GPU 인식이 안 된다(torch.cuda.is_available()==False).
#    반드시 cu124 인덱스에서 설치할 것:
#
#      pip install --index-url https://download.pytorch.org/whl/cu124 torch torchvision
#
#    (검증: RTX 4070 + 드라이버 560/CUDA12.6 → torch 2.6.0+cu124 로 CUDA=True)
#    정확한 버전 고정은 requirements-lock.txt 참조.
